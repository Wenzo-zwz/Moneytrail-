# 支付宝截图录入：兼容入口

截图流程已扩展为支付宝、微信及其他支付页面共用的 **MoneyTrail截图记账**。完整配置、识别范围和真机验收见[截图记账主指南](screenshot-bookkeeping.md)。

新指令统一使用：

```text
https://wenzo-zwz.github.io/Moneytrail-/#screenshot=
```

将 URL 编码后的手机 OCR 文字紧接在此前缀后，再打开完整 URL。截图、OCR 和确认保存仍由用户主动发起，不监听通知，不上传图片；现有 iOS 18.6.2 无需升级，不需要短信令牌或外部模型。

原名 **MoneyTrail 支付宝截图** 和旧前缀 `#alipay-screenshot=` 保留兼容。旧地址只用于接收文字，不再强制来源为支付宝；来源由明确的页面内容或用户核对决定，无法确认时按手动录入保存。可将旧指令改名并替换为新前缀，再确认“轻点背面两下”绑定整条指令。

当前仅对明确格式和有限的显式交易字段生成支出候选，不承诺任意付款截图可识别；缺少交易时间时留空补填，疑似重复仅提示，不自动合并或删除。收款、退款、转账、处理中及含糊多金额内容应人工核对。

通用入口与来源核对已实现，真实微信／其他支付样本和真机 OCR／轻点背面仍待验收；正式共享 iCloud 安装链接尚未发布。通知路线的系统能力说明见[支付宝通知与通用截图路线](alipay-notification-setup.md)。
