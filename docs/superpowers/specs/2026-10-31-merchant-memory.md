# 商户分类记忆

用户已确认：同一商户自动沿用，不同分店先确认。

首次未知的具体商户由用户明确选择大类、细类并保存后，默认记住（可取消）。以后相同商户去除已知支付渠道前缀、统一全半角后匹配，保留不同门店与公司名称差异，不做文字相似度自动合并。原交易描述与脱敏凭据保留。群收款、用途不明转账、通用渠道和平台名称不学习。

规则属于当前账户，保存大类与可选细类，明确的“未细分”可记住；旧餐饮/娱乐规则兼容为本地生活及对应细类。规则可编辑、删除。账本已有待分类先预览再补齐，已分类账目不覆盖。

覆盖普通新增/编辑、用户编辑后真正提交的导入预览、短信人工确认；纯自动导入/分类、取消、恢复备份、失败和冲突不产生示范。粘贴短信与云端短信使用相同规则。账目和学习意图先原子写入账户本机缓存，再通过带版本校验的数据库事务一起提交。离线重启保留意图，分类或商户后来改变、交易删除时丢弃过期意图；切账户不串数据。

修复已验证的抖音支付前缀缺失。数据库更新采用追加迁移，不重写历史交易；发布后可整理现有规则明确覆盖的待分类，未知商户仍待用户分类。
