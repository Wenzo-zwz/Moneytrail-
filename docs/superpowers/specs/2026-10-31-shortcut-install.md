# 快捷指令模板安装引导

已确认产品流程：用户登录并启用个人接入，导入现成普通快捷指令，通过导入问题填写自己的令牌，在手机创建信息自动化，再核对服务器实际接收。用户已提供模板并要求核对、接入网页。

## 模板与边界

- 安装链接：https://www.icloud.com/shortcuts/86d33de8ff704d6581c173b82f3f4f21
- 模板名称：MoneyTrail 慢慢记账。
- 模板固定连接 Moneytrail 的生产 Supabase 项目；其他部署不得把用户令牌导向此安装链接。
- 已解析真实共享 bplist，24 个操作；导入问题指向操作0的令牌文本，默认值和共享值为空，无真实令牌。变量UUID、ALL过滤、POST参数、status解析、三个状态分支与未知状态提示静态审核通过。安装与锁屏触发尚未经过新用户实机验证。
- 输入类型还含 AppContentItem 和 StringContentItem，不宣称严格只接受文本。网页指导触发器提取短信文本后传给模板。
- 原模板只处理工行消费短信，不能承诺支持所有银行。离线/HTTP失败可能在通知前中断，不承诺所有失败都有自定义通知。

## 网页行为

1. 保留现有启用、停用、更换令牌及记录方式控制；不自动创建、更换、撤销令牌，不改变收件箱或历史账目。
2. 在接收设置区增加默认可见的四步安装引导：个人接入、安装模板、创建短信触发、核对接收。
3. 官方模板按钮仅在已启用且项目匹配时显示可用外链；单次令牌窗口也提供安装入口。外链固定无参数，noopener/noreferrer，绝不携带令牌或短信正文。
4. 模板安装时输入个人令牌；手机自动化设置为真实银行发件人＋支出＋立即运行，提取快捷指令输入文本，运行模板并传入该文本。提醒保留不同设备/模板各自所需绑定。
5. 只展示服务器最近接收时间并复用原有刷新；接入启用不等于模板已安装或触发已设置，历史接收也不证明新模板验证成功。完整状态以收件箱的已入账/待确认为准。
6. 当前模板不支持无入账探针，本版不伪造消费或接通测试；使用实际新短信验证，明确不把收到短信等同于入账。
7. 保留手动配置折叠区供维护者/其他部署使用。面向普通用户的主流程不要求创建数据库或抄写JSON/API参数。
