# 按用途识别美团消费

用户已批准：取消美团默认餐饮；仅有平台名称的普通消费先入账待分类；补齐按摩、足浴、剧本杀、密室等娱乐词；检查历史可能误分的美团账目，并更新数据库和网页。群收款与用途不明的个人转账继续待确认。

- 分类依据采用明确用途词的包含匹配，以及用户保存的具体商户名称规则。普通“烟酒”已经可以命中购物，不依赖“烟酒副食”整个词组。
- 美团、三快公司等已知平台身份不能说明订单用途。平台身份采用窄的精确别名识别，覆盖已知公司名截断；具体门店或带有真实用途的名称仍走用途分类。
- 平台身份在个人规则之前被保护：旧平台规则不覆盖待分类结果，新规则不能把平台保存为固定类别，删除旧规则仍然可用。
- 新增娱乐词为按摩、足浴、足疗、推拿、SPA、剧本杀、密室、桌游、棋牌；保留原有医疗等用途优先级，SPA 使用 ASCII 字母边界，避免误命中 Space。
- 前端和数据库保持一致。格式、金额、日期、退款、群收款、转账与去重保护维持原有行为，手机快捷指令和令牌无需重新设置。
- 数据库迁移仅更新规则函数。历史数据另行备份、逐笔审核后，以所有者作用域和账本版本校验执行一次分类修正，不新增流水，不修改不明转账。
- 页面和文档说明平台用途不足，提供待分类结果；不会假装短信包含其未提供的订单信息。

验证包括真实入口的本地数据库集成测试、TS/SQL 共用案例、旧规则与账户隔离、前端规则编辑流程、历史修复事务回放、发布后的实际资源校验。
