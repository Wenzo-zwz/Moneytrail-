# 月度复盘、年度分类预算与分类兼容

已确认先交付分类映射和快捷指令兼容，再接预算与复盘。保留短信协议、银行识别和原有去重，账单核对与年度复盘后续处理。

## 分类

一级分类按顺序为食品酒水、居住与家用、交通出行、衣着与美妆、休闲娱乐、医疗保健、学习培训、人情往来、通讯、其他，待分类保留为待处理状态。收入和转账沿用原有类型。退款按到账月冲减原归属；关联原交易的旧退款可沿用明确细类。

旧支出按以下方式转换。保留金额、日期、来源、交易编号、备注和凭据。匹配到新分类后保留已明确的自填细类；未知用途回到待分类，仍计入总支出。

| 旧分类和细类 | 新分类 |
|---|---|
| 餐饮或本地生活下的餐饮、堂食、堂食聚餐、外卖、咖啡奶茶、买菜食材、零食饮料、酒水 | 食品酒水，餐饮、堂食、堂食聚餐统一为堂食聚餐 |
| 娱乐或本地生活下的休闲娱乐、按摩足疗、剧本杀密室、桌游台球、电影影音、电影演出、景区游玩、旅行团、健身、游戏、影音会员 | 休闲娱乐，保留原细类 |
| 单独出现的本地生活，或未命中食品、娱乐细类的本地生活 | 待分类，保留可用的原细类 |
| 购物下的服饰、服装、衣物、鞋包、配饰、护肤美妆 | 衣着与美妆，服饰与服装统一为衣物 |
| 购物下的日用品、家居维修 | 居住与家用 |
| 购物下的烟酒副食、买菜食材、零食饮料、酒水 | 食品酒水 |
| 购物下的数码 | 其他 · 数码 |
| 仅购物、超市便利或未知细类 | 待分类，保留可用的原细类 |
| 居住下明确话费、流量、宽带、通讯 | 通讯，话费流量归手机话费与流量，宽带归家庭宽带 |
| 居住下的生活缴费 | 待分类，除非用途证据明确是房屋账单或通讯 |
| 其余居住 | 居住与家用 |

| 已明确的其他、待分类 | 保留 |

网页和云端按同样的业务规则从明确用途做新的分类。通用的支付渠道、平台或商超商户不据此猜用途。具体商户可在确认时记住大类和细类，同一账户内按规范化后的具体商户复用。重复、用途不明的转账、平台名称和原有银行核对边界照常执行。未分类的真实支出由用户确认后入账。

## 实施与验证

- [x] 分类领域：定义新选项和旧类映射，兼容本机账、备份、CSV、短信草稿和个人商户规则。先用旧版完整备份与含退款的账目验证无金额变化，再逐步替换分类器与录入候选。
- [x] 云端：同一迁移支持旧式载荷、新分类、商户规则及可选年度预算。用 PGlite 验证首条明确分类后、下一条同一具体商户复用；平台和不明确转账继续待核对。保持快捷指令文件与发送格式兼容。
- [x] 预算模型：年度分类计划记录生效月份，单月计划可覆盖。用净支出比较上一月相同期间、年累计余额、剩余月均额度和独立跨年计划。确认调整只改选定月，不隐式挪动其他分类或月份。
- [x] 页面：总览月预算下的月度复盘、分类明细、设置与复盘共用年度分类预算、下月计划表单。一级包含二级，页面不合计重叠项目。
- [x] 回归：运行快捷指令校验、Vitest、TypeScript 构建与浏览器冒烟。核对旧备份、新预算备份、账号同步及两类待确认场景。

本地验证覆盖 60 个测试文件中的 2,615 项测试、生产构建和 87 项 Chrome 冒烟检查。账号版发布时，在同一次发布窗口内先应用 [分类与预算数据库迁移](../../../supabase/migrations/20261121133204_budget_taxonomy_and_annual_settings.sql)，再发布对应网页。此前加载旧版网页的设备需刷新到对应版本，现有 iPhone 快捷指令可继续使用原协议。真实账号和手机验收在对应环境进行。
