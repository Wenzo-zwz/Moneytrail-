# 农中建通用模板实施计划

**Goal:** 为农行、中行、建行的储蓄卡和信用卡提供同一套可复用短信接入模板。

**Architecture:** 公共模板源文件和匹配规则可重复构建；网页使用同一规则提供制作和配置步骤。数据库仅补充待确认接收兼容，保留工行及既有解析器。

**Tech Stack:** React、TypeScript、Python plistlib、Vitest/PGlite、Playwright、Supabase SQL迁移。

- [x] 模板源文件：克隆已审查公共模板，增加匹配动作；构建unsigned plist并测试25动作、空令牌、变量引用、安全规则和可重复生成。
- [x] 三行接收：新迁移添加边界来源识别与消费候选检查；六种卡／银行示例先红后绿，全部待确认；不变更已验证解析行为。
- [x] 网页共用指南：三行同一模板、两种卡说明、按银行名称触发；可复制匹配规则和制作说明；明确源文件待签名与分享状态。
- [x] 文档：新用户SOP、Mac一条签名命令、iPhone两处改动的制作说明；保留工行安装入口及项目匹配校验。
