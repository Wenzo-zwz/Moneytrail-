# 农行、中行、建行通用接入模板

本页为支出版本说明。需要收入时使用[银行收支模板 v3](bank-income-sms.md)，旧版筛选和安装链接不会随网页自动升级。

招商银行需要[通用银行 v2](general-bank-shortcut.md)。本页已发布的 v1 只匹配农行、中行和建行，不能作为招商银行安装链接；原三行用户可继续使用。

同一份「MoneyTrail 农中建通用记账」覆盖三家银行的储蓄卡和信用卡。每个人使用自己的慢慢记账账号及短信接入令牌；可以为多家银行分别建立短信自动化，运行同一份指令。

**[安装农中建通用模板](https://www.icloud.com/shortcuts/90ce49ad282d490481700cfe8868b82d)**。共享产物已于 2026-11-15 完成静态审核，见[交付审核记录](three-bank-shortcut-audit-2026-11-15.md)。这三家银行的记录全部先待确认；真实 iPhone 导入、授权和锁屏短信触发尚待验收，不承诺全行格式识别或自动入账。

## 新用户：注册、安装、核对手机触发

普通用户无需制作模板、签名、改代码、建立数据库或配置接口参数。

1. 打开[慢慢记账接入页](https://wenzo-zwz.github.io/Moneytrail-/?view=sms)，用自己的邮箱注册并验证后登录。iPhone 可通过 Safari 分享菜单添加到主屏幕。
2. 启用个人短信接入，复制仅显示一次的令牌。选“农业银行”“中国银行”或“建设银行”查看对应说明；银行选择只是查看指南，不是保存接收偏好。
3. 用 iPhone 打开[农中建通用版安装链接](https://www.icloud.com/shortcuts/90ce49ad282d490481700cfe8868b82d)，按导入提示粘贴自己的令牌，保留模板名称。已有有效令牌可沿用，无需为安装重新生成；工行原模板继续只用于工行。
4. 在实际 iOS 版本的“快捷指令”中核对或设置短信自动化：选择实际给自己发短信的银行号码，并按设备提供的选项设置立即运行。短信包含内容按下表填写。

| 银行 | 信息包含 | 卡种 | 运行指令 |
| --- | --- | --- | --- |
| 农业银行 | 农业银行 | 储蓄卡／信用卡 | MoneyTrail 农中建通用记账 |
| 中国银行 | 中国银行 | 储蓄卡／信用卡 | 同上 |
| 建设银行 | 建设银行 | 储蓄卡／信用卡 | 同上 |

5. 核对短信正文的传递：先从“快捷指令输入”获取文本，再运行通用版，**输入明确绑定上一步的文本**。本次共享产物是普通快捷指令，不能仅凭安装成功认定个人短信触发已设置；如系统提供自动化分享或导入入口，也要核对导入后的发件人、筛选条件和输入。具体操作以设备和系统版本显示为准。
6. 等待下一条真实消费短信，核对通知、网页最近接收时间及待确认记录。确认金额、时间、商户和交易类型后保存。确认入账后，首页在当前月份自动同步；群收款、用途不明转账继续人工核对。

若同时使用三家银行，可分别配置触发，运行同一份模板。只选择自己实际需要的发件人；银行常见号码仅作参考，以真实短信为准。首次授权和锁屏触发请按[首次试用验收清单](automatic-bookkeeping-rollout.md)逐项核对。

## 当前接收范围

- 接收前后边界带有明确银行标记的消费候选，如 `【中国农业银行】`、`（中国银行）`、`【建设银行】`；支持简称及相应半角括号。
- 支出、消费、扣款等词需与交易金额对应；消费金额与余额、可用额度分开处理。字段不全或未知格式保留待确认，不编造数据。
- 验证码、安全口令、纯收入、促销、账单／还款提醒、明确外币及冲突银行来源不转为消费。无银行标记的短信需后续样本适配，不能自行添加签名绕过校验。
- 网上整理的六种银行／卡种正文仅用于兼容测试，当前均不会自动入账；后续提供脱敏实机样本再验证具体格式。
- 本模板转发银行短信，不会自动读取微信或支付宝通知。既有短信不会因安装而自动导入；断网失败也需恢复网络后核对并补录。

## 维护者：更新源文件、签名和重新分享

现有共享链接可供新用户直接安装。下面是维护者制作后续版本的方法，无需每位用户重复执行。所有分享副本的令牌文本和导入问题默认答案均须为空；个人使用副本另行保存。

### 使用 Mac 签名源文件

签名方法依据 [Apple 命令行说明](https://support.apple.com/en-hk/guide/shortcuts-mac/apd455c82f02/mac)，分享方式依据 [Apple 分享说明](https://support.apple.com/guide/shortcuts-mac/share-shortcuts-apdf01f8c054/mac)。

1. 在 Mac 下载[模板源文件](https://wenzo-zwz.github.io/Moneytrail-/shortcuts/moneytrail-three-bank-v1.unsigned.plist)，保存到“下载”文件夹，保留文件名。它是未签名 XML，不是可直接安装的快捷指令。
2. 使用 Apple 自带的“快捷指令”命令签名：

```sh
shortcuts sign --mode anyone --input "$HOME/Downloads/moneytrail-three-bank-v1.unsigned.plist" --output "$HOME/Downloads/MoneyTrail 农中建通用记账.shortcut"
```

3. 输出文件可供 iPhone 导入，也可在 Mac 的“快捷指令”中打开并分享或导出给“任何人”。具体菜单以当前系统显示为准；签名失败时保留报错，不把源文件直接改名冒充已签名文件。
4. 将新链接或签名文件交给维护者核验空令牌、导入问题、筛选规则、输入变量、请求地址和状态反馈后，再交付用户。网页更新不会自动更新用户手机中的旧指令。

### 使用 iPhone 从工行基础模板制作

1. 复制[工行基础模板](https://www.icloud.com/shortcuts/86d33de8ff704d6581c173b82f3f4f21)，将副本重命名为 **MoneyTrail 农中建通用记账**，保留原指令。
2. 在“将变量 短信正文 设为 文本”之后、第一个“如果”之前加“匹配文本”，输入选“短信正文”，关闭区分大小写，使用仓库标准源文件中的完整匹配规则。
3. 将第一个“如果”改为“匹配文本有任何值”，引用新增匹配动作的输出，移除旧工行条件。保留请求、中文通知和控制流结构。
4. 清空令牌文本和导入默认答案后，通过设备提供的分享入口生成链接；另用个人副本填写自己的令牌实测。分享方式及自动化导入能力按实际 iOS 版本核对。

这两处流程改动将工行模板的 24 个操作变成 25 个操作；发布前仍须重新审查实际共享产物，不能只核对屏幕上的动作名称。

## 源文件与验证

源文件：`shortcuts/moneytrail-three-bank.template.json`。公共规则与说明：`public/shortcuts/three-bank-profile.json`。均不包含个人令牌、账号 ID 或卡尾号。

```sh
python scripts/build-bank-shortcut.py
python scripts/build-bank-shortcut.py --check
```

构建只生成未签名 XML，不会访问 Apple、代签、上传短信或产生 iCloud 链接。静态测试核对 25 操作、变量引用、导入问题、匹配规则、请求与中文状态反馈；Apple 导入、权限和真实短信自动触发仍需 Apple 设备验证。
