# 农行、中行、建行通用接入模板

同一份「MoneyTrail 农中建通用记账」覆盖三家银行的储蓄卡和信用卡。每个人使用自己的慢慢记账账号及短信接入令牌；可以为多家银行分别建立短信自动化，运行同一份指令。

当前是**通用流程和模板源文件已准备，Apple 签名／iCloud 分享待完成**。这三家银行的记录全部先待确认；尚无同事实机短信验证，不承诺全行格式识别或自动入账。

## 制作者：准备一次即可复用

### 方式一：使用 Mac 签名

签名是 Apple 对快捷指令文件的验证。生成的源文件需经过这一步，才能作为 `.shortcut` 文件交给 iPhone 导入。签名方法依据 [Apple 命令行说明](https://support.apple.com/en-hk/guide/shortcuts-mac/apd455c82f02/mac)，分享方式依据 [Apple 分享说明](https://support.apple.com/guide/shortcuts-mac/share-shortcuts-apdf01f8c054/mac)。

1. 在 Mac 下载[模板源文件](https://wenzo-zwz.github.io/Moneytrail-/shortcuts/moneytrail-three-bank-v1.unsigned.plist)，保存到“下载”文件夹，保留文件名。它是未签名 XML，不是可以直接安装的快捷指令。
2. 打开 Mac 的“终端”，复制运行这一条命令：

```sh
shortcuts sign --mode anyone --input "$HOME/Downloads/moneytrail-three-bank-v1.unsigned.plist" --output "$HOME/Downloads/MoneyTrail 农中建通用记账.shortcut"
```

3. 输出文件在“下载”文件夹中。可将签名后的 `.shortcut` 文件交给 iPhone 导入；也可在 Mac 的“快捷指令”中打开，再用“分享 → 复制 iCloud 链接”。也可通过“文件 → 导出”选择“任何人”。
4. 发布副本中的令牌文本和导入问题默认答案都应为空。每位安装者在导入时填写自己的令牌。
5. 把新的分享链接或已签名文件交给维护者核验。网页在核验前继续显示“共享安装链接尚未发布”，不会把工行链接或未签名源文件冒充通用安装包。

需要 Apple 自带的“快捷指令”命令。签名失败时保留完整报错，不要把源文件直接改名为 `.shortcut` 当作已签名文件。

### 方式二：使用 iPhone 改两处再分享

1. 安装或复制[现有工行基础模板](https://www.icloud.com/shortcuts/86d33de8ff704d6581c173b82f3f4f21)，将副本重命名为 **MoneyTrail 农中建通用记账**，保留正在使用的原指令。
2. 在“将变量 短信正文 设为 文本”之后、第一个“如果”之前，加一条**匹配文本**。输入选“短信正文”，关闭区分大小写；从网页“短信自动记账 → 农中建通用模板 → 制作与分享模板”复制匹配规则，完整粘贴。
3. 将第一个“如果”改为**匹配文本有任何值**，移除旧条件。保留其中的发送请求、中文通知和控制流结构。
4. 将副本最上面的令牌文本清空，导入问题默认答案留空，再点击“分享 → 复制 iCloud 链接”。用另外的个人副本填写自己的令牌做实机验证。

步骤 2、3 是唯一两处流程改动：从已审查的 24 个操作变成 25 个操作。网页提供“复制 iPhone 制作步骤”，包含基础模板链接、完整匹配规则和变量绑定说明。

## 同事：注册、安装、设置触发

1. 打开[慢慢记账接入页](https://wenzo-zwz.github.io/Moneytrail-/?view=sms)，用自己的邮箱注册并验证后登录。iPhone 可通过 Safari 分享菜单添加到主屏幕。
2. 启用个人短信接入，复制仅显示一次的令牌。选“农业银行”“中国银行”或“建设银行”查看对应说明；银行选择只是查看指南，不是保存接收偏好。
3. 安装制作者完成签名或分享的**农中建通用版**。在导入问题中粘贴自己的令牌。当前工行分享链接仍是基础模板，必须先完成上面的两处修改才适用于三行。
4. 在“快捷指令 → 自动化”新建“信息”，选择实际给自己发短信的银行号码，设置立即运行。短信包含内容按下表填写。

| 银行 | 信息包含 | 卡种 | 运行指令 |
| --- | --- | --- | --- |
| 农业银行 | 农业银行 | 储蓄卡／信用卡 | MoneyTrail 农中建通用记账 |
| 中国银行 | 中国银行 | 储蓄卡／信用卡 | 同上 |
| 建设银行 | 建设银行 | 储蓄卡／信用卡 | 同上 |

5. 添加“获取文本”，来源选“快捷指令输入”；再添加“运行快捷指令”，选择通用版，**输入明确绑定上一步的文本**。导入普通指令不会自动创建个人短信触发。
6. 等待下一条真实消费短信，核对通知、网页最近接收时间及待确认记录。确认金额、时间、商户和交易类型后保存。确认入账后，首页在当前月份自动同步；群收款、用途不明转账继续人工核对。

若同时使用三家银行，可分别创建三条触发，运行同一份模板。只选择自己实际需要的发件人；银行常见号码仅作参考，以真实短信为准。

## 当前接收范围

- 接收前后边界带有明确银行标记的消费候选，如 `【中国农业银行】`、`（中国银行）`、`【建设银行】`；支持简称及相应半角括号。
- 支出、消费、扣款等词需与交易金额对应；消费金额与余额、可用额度分开处理。字段不全或未知格式保留待确认，不编造数据。
- 验证码、安全口令、纯收入、促销、账单／还款提醒、明确外币及冲突银行来源不转为消费。无银行标记的短信需后续样本适配，不能自行添加签名绕过校验。
- 网上整理的六种银行／卡种正文仅用于兼容测试，当前均不会自动入账；后续提供脱敏实机样本再验证具体格式。
- 本模板转发银行短信，不会自动读取微信或支付宝通知。既有短信不会因安装而自动导入；断网失败也需恢复网络后核对并补录。

## 源文件与验证

源文件：`shortcuts/moneytrail-three-bank.template.json`。公共规则与说明：`public/shortcuts/three-bank-profile.json`。均不包含个人令牌、账号 ID 或卡尾号。

```sh
python scripts/build-bank-shortcut.py
python scripts/build-bank-shortcut.py --check
```

构建只生成未签名 XML，不会访问 Apple、代签、上传短信或产生 iCloud 链接。静态测试核对 25 操作、变量引用、导入问题、匹配规则、请求与中文状态反馈；Apple 导入、权限和真实短信自动触发仍需 Apple 设备验证。
