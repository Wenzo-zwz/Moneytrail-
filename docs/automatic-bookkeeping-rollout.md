# 短信自动记账：首次试用验收清单

这份清单用于维护者交付模板和新用户首次试用。普通试用者只需自己的 iPhone、邮箱账号和个人接入令牌，**不需要改代码、建数据库、执行 SQL 或配置 API 参数**。服务配置由维护者负责；页面提示服务未开通时，由维护者排查。

## 先按银行选择试用范围

| 范围 | 当前交付状态 | 首次试用预期 |
| --- | --- | --- |
| 工商银行 | [工行模板可安装](https://www.icloud.com/shortcuts/86d33de8ff704d6581c173b82f3f4f21) | 选择自动记录时，符合规则的明确消费可直接入账；群收款、不明用途和未知格式仍可能待确认 |
| 农业银行、中国银行、建设银行 | 共用模板源文件已准备，Apple 签名／iCloud 分享待完成 | 储蓄卡、信用卡共用流程；符合接收范围的短信全部先待确认，不承诺全部格式可识别 |
| 其他银行 | 尚无对应模板与接收承诺 | 使用手动录入或账单导入，不套用现有银行模板 |

银行说明和兼容测试不等于实机验证。每个银行、卡种和设备的结果分别记录；通过一组不能推断其他组已通过。

## 维护者：交付一次，供多人安装

- [ ] 农中建模板按[制作说明](three-bank-shortcut.md)在 Apple 设备完成签名或 iCloud 分享，提供实际可导入的文件或链接。未签名 plist 不能当安装包，工行链接不能当三行安装链接。
- [ ] 核验发布副本：令牌文本、导入问题默认答案均为空，不含个人账号或短信；接收地址与公开密钥属于预期部署。共享模板固定连接生产服务，其他部署须提供自己的配套模板。
- [ ] 用新安装副本核对导入问题能填写个人令牌，短信输入和请求流程保留；记录模板版本及交付链接。公共副本与个人使用副本分开保存，个人令牌不进入分享副本。
- [ ] 核验产物后再开放相应安装入口；取得产物前保留“待发布”状态。网页更新不会自动更新手机里已安装的指令。

Mac 签名和 iPhone 制作方法见[农中建模板说明](three-bank-shortcut.md)；完整接入及排查见[短信自动化说明](sms-automation.md)。无需把维护者的制作步骤交给每位普通用户重复执行。

## 新用户：完成自己手机上的一次配置

- [ ] 打开[短信接入页](https://wenzo-zwz.github.io/Moneytrail-/?view=sms)，使用自己的邮箱注册、验证并登录。不同人使用独立账号，不共用账本或登录凭据。
- [ ] 启用个人接入，保存仅显示一次的个人令牌；在模板导入问题中填写自己的令牌。令牌只交给自己的快捷指令，不发到聊天或共享链接。已有有效令牌可沿用，无需为安装模板更换。
- [ ] 安装与自己银行、当前部署相匹配的已交付模板。农中建模板尚未交付时，等待维护者提供可安装产物。
- [ ] 按网页对应银行说明创建个人短信自动化，选择真实发件人并明确把收到的短信文本传入指令。安装普通快捷指令不会同时创建短信触发；网页的银行选择也不会修改手机配置。
- [ ] 按设备实际提示完成首次授权，记录 iPhone 型号、系统版本、银行及卡种。具体菜单以设备显示为准。

## 用下一条真实短信验收

不要为测试提交虚构消费，也不必为了验收额外消费。等待下一笔正常交易的真实短信；保留当前指令的输入变量，不把正文写死在指令里。

- [ ] 在手机锁屏、正常联网的情况下，收到一条新的符合条件的银行短信后，核对通知，并在网页刷新最近接收时间和收件箱。手动运行、旧接收时间或“接入已启用”不能代替此次自动触发验证。
- [ ] 比对原短信与账目：金额、日期、商户和交易类型正确；余额未被当作消费。字段不全时保持待确认，由本人补齐，不修改原短信来绕过规则。
- [ ] 按实际返回结果核对下表；待确认记录保存前不计入首页消费。确认或自动入账后，等待同步完成，再核对首页对应月份的金额及记录数量。
- [ ] 至少两名试用者各用独立账号和令牌完成接收，分别登录后只看到自己的收件箱及账本，不互相代填令牌。

| 结果 | 应核对的事实 |
| --- | --- |
| `recorded` | 已入账；账本中存在对应的一笔记录，金额和类型正确 |
| `pending` | 已接收待确认；处理前不增加消费，确认后才入账 |
| `duplicate` | 同一正文最近 24 小时已接收过，本次未新增；仍需找到原记录，不能据此认定原记录已入账 |
| 断网、报错或没有通知 | 结果可能不明；先恢复网络并核对收件箱和账本。此接入没有自动离线补传队列，确认漏记后再用真实原文重发或手动补录 |

通知可能在网络或接口失败前未能显示，不能只凭通知判断结果。历史短信不会因安装模板自动导入；不要修改时间、金额或商户规避重复检查。

## 记录结果，再扩大试用

每次记录：日期、模板版本、设备／系统、银行／卡种、锁屏与联网情况、通知状态、网页接收时间、入账或待确认结果，以及是否重复。未遇到的状态标为“未验证”，不要补写为通过。

验收记录或反馈截图需隐藏邮箱、卡号、余额及其他私人信息，不包含个人令牌或完整短信。失败时记录具体停在哪一步及脱敏报错；维护者据此排查。完成 Apple 导入、独立账号接收和真实锁屏触发后，再对已验证的银行与设备扩大试用。
